# 1304 - Οργάνωση και Αρχιτεκτονική Υπολογιστικών Συστημάτων 💻

Καλώς ήρθατε στο αποθετήριο (repository) του μαθήματος **"1304: Οργάνωση και Αρχιτεκτονική Υπολογιστικών Συστημάτων"**. 

Αυτό το project αποτελεί έναν πλήρη οδηγό μελέτης και περιέχει τις λύσεις από όλες τις εργαστηριακές ασκήσεις του εξαμήνου, καθώς και λυμένα θέματα παλαιότερων εξετάσεων. Η ύλη χωρίζεται σε δύο βασικούς πυλώνες: τον προγραμματισμό μικροεπεξεργαστών (Assembly x86) και τον προγραμματισμό μικροελεγκτών (Arduino / C++).

---

## 📂 Δομή του Αποθετηρίου

Το repository είναι οργανωμένο στους παρακάτω 3 κεντρικούς φακέλους:

### 1. [01_Assembly_Labs](./01_Assembly_Labs)
Περιέχει προγράμματα γραμμένα σε **Συμβολική Γλώσσα Μηχανής (Assembly 8086)**. Τα προγράμματα έχουν αναπτυχθεί και ελεγχθεί στον εξομοιωτή `emu8086`.
* **Βασικές Λειτουργίες:** Μαθηματικές πράξεις, χρήση καταχωρητών (Registers) και στοίβας (Stack).
* **Διαχείριση Ροής & Μνήμης:** Έλεγχοι (Άρτιος/Περιττός), δομές επανάληψης (Loops) και Arrays.
* **DOS Interrupts (INT 21h):** Είσοδος/Έξοδος δεδομένων και αλληλεπίδραση με τον χρήστη.
* **Υποπρογράμματα (Procedures):** Πέρασμα παραμέτρων και διαχείριση strings (Μετατροπές Κεφαλαία-Μικρά).

### 2. [02_Arduino_Labs](./02_Arduino_Labs)
Περιέχει προγράμματα γραμμένα σε **C++ για τον μικροελεγκτή Arduino Uno**. Κάθε εργαστήριο βρίσκεται σε ενοποιημένο αρχείο `.ino` (χρήση `#define EXERCISE` για επιλογή άσκησης).
* **Ψηφιακή & Αναλογική I/O:** Έλεγχος LED, χρήση Push Buttons (`INPUT_PULLUP`) και Ποτενσιόμετρων (PWM & `map()`).
* **Χρονισμός & Πολυδιεργασία:** Αντικατάσταση της `delay()` με την `millis()` για ταυτόχρονη εκτέλεση εντολών.
* **Hardware Interrupts & Αισθητήρες:** Χρήση ρουτινών διακοπής (ISR - `attachInterrupt`) για ακαριαία απόκριση και ανάγνωση αισθητήρα θερμοκρασίας (TMP36).
* **Περιφερειακά (Peripherals):** Προχωρημένη οδήγηση περιφερειακών συστημάτων. Περιλαμβάνει τη χρήση οθόνης χαρακτήρων HD44780 LCD (Scrolling Text & προβολή δεδομένων), μέτρηση απόστασης με αισθητήρα υπερήχων (Ultrasonic HC-SR04) και έλεγχο γωνίας κινητήρα (Servo Motor) με χρήση της συνάρτησης αναγωγής `map()`.

## 🚀 Πώς να τρέξετε τον κώδικα

- **Για τα αρχεία Assembly (`.asm`):** Απαιτείται ο εξομοιωτής [emu8086](https://emu8086.en.softonic.com/). Ανοίξτε το αρχείο, πατήστε `Emulate` για τη μεταγλώττιση και στη συνέχεια `Run`.
- **Για τα αρχεία Arduino (`.ino`):** Μπορείτε να ανοίξετε τον κώδικα στο επίσημο [Arduino IDE](https://www.arduino.cc/en/software) για να τον φορτώσετε σε φυσική πλακέτα, ή να κάνετε copy-paste τον κώδικα στο [Tinkercad Circuits](https://www.tinkercad.com/) για προσομοίωση κυκλωμάτων.
